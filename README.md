# LPU Semester CGPA Calculator

A sleek, responsive, and robust web application designed for Lovely Professional University (LPU) students to track their semester marks, calculate their SGPA, and estimate their CGPA.

## 🚀 Features

- **Dynamic Cycle Selection**: Seamlessly toggle between the **MEC Cycle** (Engineering Physics, Engineering Drawing, etc.) and the **ECE Cycle** (Basic Electrical/Electronics, Environmental Studies).
- **Real-Time Grade Calculation**: Instantly calculates your letter grades (O, A+, A, etc.) as you input marks for individual components like Attendance, Continuous Assessment, Mid Term, and End Term.
- **SGPA & CGPA Estimation**: Features a dynamic circular progress indicator for your SGPA and a progress bar for your estimated CGPA.
- **Detailed PDF Export**: Generates a professional, fully-formatted native PDF report detailing your subject breakdown, earned credits, component marks, and overall academic summary.
- **Premium UI/UX**: Designed with a clean, modern "greenish" theme, featuring soft shadows, smooth micro-animations, and a fully functional Dark Mode toggle.
- **Persistent Storage**: Utilizes `localStorage` so your entered marks are saved automatically across page refreshes.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure.
- **CSS3 (Vanilla)**: Custom CSS variables for theming, responsive CSS Grid/Flexbox layouts, and smooth transition effects.
- **JavaScript (Vanilla)**: Core calculation logic, DOM manipulation, state management, and native PDF generation using `jsPDF`.
- **FontAwesome**: Scalable vector icons for a polished interface.

## 📥 Installation & Usage

1. Clone or download this repository.
2. Ensure you have the following files in the root directory:
   - `index.html`
   - `style.css`
   - `script.js`
   - `logo.png` (The application's logo/favicon)
3. Simply open `index.html` in any modern web browser (Google Chrome, Firefox, Safari, Edge).
4. Select your cycle, input your component marks, and watch your grades update in real-time. Click **Export PDF** to download your semester report!
